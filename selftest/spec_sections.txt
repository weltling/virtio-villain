# virtio device registry and spec section map for the traceability guard.
#
# Source of truth: the OASIS virtio-spec content.tex Device Types table
# (device id -> name) and the \input order that assigns chapter 5 numbers.
# Verified against tags v1.2-cs01, v1.3-wd02 and v1.4-cs01.
#
# This lists EVERY device id in the registry for every supported version,
# not only the ones virtio-villain tests. Most ids have no normative
# chapter; their chapter columns are "-". A device id present only from a
# later version still gets a row (its chapter is "-" until it gains one).
#
# Numeric chapters are 1..7 (Introduction, Basic Facilities, General
# Initialization, Virtio Transport Options, Device Types, Reserved Feature
# Bits, Conformance). Appendices are lettered, so no numeric chapter >= 8
# exists; that is the max_chapter rule at the bottom.
#
# Columns:
#   id    virtio device id (decimal)
#   key   virtio-villain test directory name, or a slug if untested
#   V1_x  the device's chapter in that version, or "-" for none
# The trailing comment gives the spec device name (and notes renames).
#
# When bumping to a new spec version add a V column here and an @Vx_y rule
# row, after rechecking the Device Types table and \input order.
